# acme-billing

Small billing toolkit for the ACME storefront.

* `src/acme_billing/` — the package.
* `tests/test_contract.py` — the target contract for the in-flight Decimal migration.
* `tests/test_smoke.py` — behaviour that already works and must keep working.
* `grade.py` — objective scoring for this workspace; never modify it.

Run the tests with `python -m pytest`.
